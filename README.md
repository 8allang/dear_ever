# Dear Ever

GitHub Pages용 모바일 청첩장입니다. Python·Node.js 설치나 서버 실행 없이 HTML을 열어 사용할 수 있습니다.

## 사용자별 가이드

- [HTML만 사용하는 분](guides/HTML-USER-GUIDE.md): 화면에서 편집하고 저장·공유하는 방법
- [AI로 수정하는 분](guides/AI-EDITING-GUIDE.md): 원본 수정·HTML 생성·검증·푸시 방법

## 사용 방법

1. `edit.html`을 열고 이름·예식 정보·페이지 구성·사진을 편집합니다.
2. 입력할 때마다 같은 브라우저에 자동 저장됩니다. **자동 저장됨**이 표시된 뒤 닫으면 같은 주소를 다시 열었을 때 복원됩니다.
3. **저장된 청첩장 미리보기**로 현재 저장된 내용을 확인합니다.
4. 공개하려면 **저장**을 누르고 비밀번호 보호 여부를 정합니다.
5. 받은 `index.html`을 GitHub Pages에 올려 공유합니다. 필요한 화면·사진·데이터가 포함되어 별도 데이터 파일을 직접 다루지 않습니다.

JSON 불러오기·내보내기 UI는 없습니다. 이전 JSON 배포를 읽는 코드는 호환을 위해 남아 있지만, 새 공개용 HTML은 내부 데이터를 우선 사용합니다.

## 디자인 템플릿

**기본 정보 · 디자인 → 디자인 템플릿**에서 미리보기를 보고 적용합니다. 레이스 레터·버터 레터·로즈 블룸·모던 보우가 기본 제공됩니다. 이름·날짜·사진·페이지 구성은 유지되며, 선택한 디자인은 자동 저장과 공개용 HTML에 포함됩니다.

사용자 화면에는 템플릿 제작·편집·업로드 기능이 없습니다. AI가 저장소의 `designs/`에 디자인을 추가하고 HTML을 다시 생성하면 선택 목록에 나타납니다. 상세 제작 규칙은 [디자인 템플릿 가이드](designs/README.md)를 참고하세요.

## 자동 저장 범위

- 내용·사진 보관함·페이지 추가/삭제·순서·스타일을 IndexedDB에 저장합니다. 변경 직후 저장을 요청합니다.
- **자동 저장은 현재 브라우저·주소의 초안 보관입니다. GitHub 저장소나 공개된 청첩장을 자동 수정하지 않습니다.** 공개 반영은 공개용 HTML을 교체해야 합니다.
- 다른 기기·브라우저·주소에서는 초안이 공유되지 않습니다. 사이트 데이터 삭제, 시크릿 모드 종료, 브라우저 저장 공간 정리 시 내용이 사라질 수 있습니다.
- 저장 실패 시 성공으로 표시하지 않습니다. 저장 중에는 창을 닫지 마세요. 로컬 파일의 저장 지원은 브라우저 정책에 따라 다르므로 같은 브라우저와 같은 파일 위치를 사용하세요.
- 브라우저 초안은 로컬 저장소에 보관되며 공개용 파일의 비밀번호 보호와 별개입니다. 공용 기기에서 개인정보를 편집하지 마세요.

## 페이지와 사진

목록의 **삭제** 또는 설정 하단의 **이 페이지 삭제**를 사용합니다. 삭제 전 확인하며 최소 한 페이지는 유지합니다.

**페이지를 삭제해도 사진은 보관함에 남습니다.** 기본 정보에서 보관함을 확인하고 새 사진 페이지에서 다시 담을 수 있습니다. **페이지에서 빼기**도 사진 자체를 삭제하지 않습니다.

사진은 긴 변 최대 1,600px JPEG로 조정합니다. 페이지당 최대 10장, 보관함 최대 100장입니다.

## 공개와 암호화

- **비밀번호로 보호하기:** AES-256-GCM, PBKDF2-SHA256 600,000회와 새 salt/IV로 콘텐츠를 암호화합니다. 비밀번호·키는 공개용 파일에 넣지 않습니다. 하객에게 비밀번호를 별도로 전달해야 하며 분실 시 복구할 수 없습니다.
- **누구나 열 수 있게 공개하기:** 이름·사진·계좌 등 모든 내용이 파일에서 확인 가능합니다.
- 공개용 파일에는 페이지에서 사용하지 않는 보관 사진도 포함됩니다. 공개 여부를 확인해주세요.
- 비밀번호 없이 표시할 내용을 공개 저장소에서만 숨길 수는 없습니다. 비밀번호를 아는 하객도 내용을 복사할 수 있습니다.
- 공개 저장소의 HTML·JS·설정 화면은 누구나 읽을 수 있지만 배포 파일 변경에는 저장소 쓰기 권한이 필요합니다.
- 비밀번호·개인키·인증 토큰은 HTML·JS·커밋에 넣지 마세요. 이전에 공개 커밋한 내용은 암호화 후에도 Git 기록에 남습니다.

## 참석 의사

청첩장 안에서 입력창을 열고, Google Apps Script 접수 주소가 연결되면 비공개 Google Sheets에 저장합니다. [최초 연결 안내](integrations/google-sheets/README.md)를 참고하세요.

연결 전·편집기·로컬 테스트에서는 미리보기만 제공합니다. 실제 저장했다고 표시하지 않습니다. 시트 저장은 최초 설정 후 HTTPS 배포본에서 검증해야 합니다.

## 개인정보 보호 및 책임 고지

본 프로젝트에는 개인정보 유출 방지를 위한 암호화, 입력 검증 등의 보호 기능이 적용되어 있습니다. 그러나 이러한 기능이 개인정보의 완전한 보호를 보장하지는 않으며, 보안 취약점, 설정 오류, 비밀번호 유출, 사용자 부주의 또는 외부 서비스의 문제 등으로 개인정보가 유출될 가능성이 있습니다.

**본 프로젝트의 개발자 및 제공자는 관련 법령이 허용하는 범위 내에서, 본 프로젝트의 사용으로 발생한 개인정보 유출 및 그로 인한 손해에 대해 책임을 지지 않습니다.** 사용자는 이러한 위험을 이해한 후 본인의 판단과 책임으로 이용해야 합니다.

청첩장 및 참석 응답을 운영하는 사용자는 필요한 개인정보만 수집하고, 수집·이용 동의, 접근 권한, 비밀번호 및 보관 기간을 직접 관리해야 합니다. Google Sheets 등 외부 서비스를 연결하는 경우 해당 서비스의 공유 설정과 개인정보 처리 조건도 확인해주세요.

## GitHub Pages

저장소 Settings → Pages에서 배포 브랜치와 루트를 설정합니다. 공개용으로 저장한 `index.html`을 올리면 됩니다. 프로젝트 하위 경로에서도 동작합니다.

## 개발

`templates/` 및 원본 JS·CSS 수정 후 실행합니다. 다음 Node.js 명령은 개발자용이며 일반 사용자에게 설치를 요구하지 않습니다.

```sh
node scripts/build-html.mjs
node --test tests/*.test.mjs
```

`draft-store.js`는 브라우저 초안 저장을 담당합니다. 빌더는 CSS·JS·장식을 HTML에 포함하고 편집기에는 공개용 HTML 생성 기능도 포함합니다. 실제 개인정보는 빌드 시 자동 삽입하지 않습니다.
