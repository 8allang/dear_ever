# AI가 관리하는 디자인 템플릿

디자인은 이 폴더에 여러 개 저장하고 `catalog.json`에 등록합니다. HTML 사용자는 편집기의 **디자인 템플릿 → 적용**만 사용합니다. 템플릿을 제작·수정·업로드하는 UI는 제공하지 않습니다.

이 구분은 제품의 사용 흐름입니다. 공개 저장소의 코드 자체를 읽거나 복사하는 것을 막는 기능은 아닙니다. 실제 공식 HTML을 갱신하려면 저장소 수정·배포 권한이 필요합니다.

## 파일 구조

- `catalog.json`: HTML에 포함할 디자인 ID 목록과 형식 버전
- `<id>.json`: 디자인 이름·설명·버전·이전 테마와의 호환 정보
- `<id>.css`: 해당 디자인에만 적용할 스타일
- 루트 `design-catalog.js`: 빌더가 생성하는 실행용 목록. 직접 수정하지 않습니다.
- 루트 `designs.js`: 등록된 디자인 찾기·적용·이전 데이터 호환

기본 디자인은 `lace-letter`, `butter-letter`, `rose-bloom`, `modern-vow`입니다.

## AI에게 새 디자인 요청하기

```text
AGENTS.md와 designs/README.md를 읽고 새로운 디자인 템플릿을 추가해줘.
기존 디자인 파일은 남겨두고 별도 ID로 저장해줘.
일반 사용자에게는 미리보기와 적용 버튼만 보여줘.
페이지 내용·사진·순서를 바꾸지 않도록 해줘.
HTML 재생성과 관련 테스트, 모바일 화면 검수를 해줘.
```

## 등록 순서

1. 영문 소문자로 시작하고 소문자·숫자·하이픈으로 구성한 고유 ID를 정합니다. 최대 60자입니다.
2. 다음 형식의 `<id>.json`을 작성합니다.

```json
{
  "id": "new-design",
  "version": 1,
  "name": "디자인 이름",
  "description": "사용자에게 보여줄 짧은 설명",
  "legacyTheme": "lace"
}
```

`legacyTheme`은 `lace`, `butter`, `rose` 중 하나입니다. 사용자 콘텐츠나 사진, 비밀번호, HTML, 스크립트, 외부 주소를 메타데이터에 넣지 않습니다. 허용되지 않은 필드는 빌드가 거부합니다.

3. `<id>.css`를 작성합니다. **모든 선택자는 `.design-<id>`로 시작**해야 합니다.

```css
.design-new-design{--paper:#faf8f1;--ink:#514b40;--tint:#eae5d7;--accent:#97876d}
.design-new-design .section-cover{background:var(--paper)}
.design-new-design .section-cover h1{font-size:30px}
```

`body`, `.invitation`처럼 전체 화면에 영향을 주는 단독 선택자는 허용하지 않습니다. 외부 자산 요청·스타일 삽입을 피하기 위해 템플릿 CSS의 `url()`, `@import` 및 기타 `@` 규칙도 허용하지 않습니다. 반응형 크기는 `clamp()`, `%`, `rem` 등과 기존 공통 레이아웃을 활용하세요. 새로운 공통 자산이 필요하다면 AI가 기존 빌드·CSP와 함께 원본을 수정하고 검수해야 합니다.

4. `catalog.json`의 `templates` 배열에 ID를 추가합니다. 목록 순서가 편집기 표시 순서입니다.
5. HTML을 재생성합니다.

```sh
node scripts/build-html.mjs
node --test tests/*.test.mjs
```

6. 편집기 미리보기 카드와 실제 적용 결과를 모바일에서 확인합니다. 원본·생성된 카탈로그·HTML을 함께 반영합니다.

## 적용 및 호환 규칙

- 콘텐츠에는 등록된 디자인의 ID를 저장합니다. 사용자 입력의 CSS나 HTML을 실행하지 않습니다.
- 이름·날짜·사진 보관함·페이지 내용·순서·표시 여부·페이지별 배경 설정은 그대로 둡니다.
- 선택 결과는 브라우저 초안과 공개용 HTML에 남습니다. 모든 디자인 코드가 HTML에 포함되므로 직접 열기에서도 외부 파일을 선택할 필요가 없습니다.
- 기존 초안에 디자인 ID가 없으면 이전 테마와 맞는 기본 디자인을 표시합니다. 사라진 ID도 호환 테마로 표시하므로 사용자 콘텐츠를 초기화하지 않습니다.
- 이미 저장한 공개용 HTML은 당시 디자인 코드가 포함된 독립 파일입니다. 새 디자인 추가가 기존 배포 파일을 자동 변경하지 않습니다.
- 기존 디자인을 갱신할 때는 버전을 올립니다. 별도 보관할 변형이라면 새로운 ID로 추가하세요.
